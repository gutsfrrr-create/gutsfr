GUTS — DARK FANTASY ART ARCHIVE

HOW TO OPEN
1. Extract the ZIP folder.
2. Open index.html in a modern browser.
3. Keep index.html, style.css, script.js, and the images folder together.

WHAT'S UPDATED
- Replaced the old screenshot crops with the 10 original artwork uploads.
- Gallery and lightbox use the original image files at their native dimensions, with responsive sizing and contain-fit display to avoid cropping artwork.
- Reworked the visual mood toward gothic dark fantasy: blood-red accents, knightly framing, charcoal backgrounds, runic glows, ember drift, and scroll reveal animations.
- Preserved the GUTS artist identity and Instagram link (@guts.7r).
- Includes category filters, clickable artwork viewer, keyboard navigation, and mobile responsive layout.

NOTE ON IMAGE QUALITY
The site displays the provided original files without artificially enlarging or recompressing them. CSS keeps them crisp and prevents the gallery from cropping the compositions. Upscaling cannot restore detail that is not present in the source file.

This is a local static website package; it is not automatically published online.
